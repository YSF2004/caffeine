# Caffeine

A warm, multi-page site for a specialty coffee space — home, about, history,
gallery, products and contact. Built with plain HTML, CSS and JavaScript on a
cream-and-espresso palette.

## Pages

- `index.HTML` — home
- `About.HTML` — about
- `History.HTML` — history
- `Gallery - Copy.HTML` — gallery
- `Special products.HTML` — products
- `Contact.HTML` — contact

Open `index.HTML` in a browser to view the site; no build step required.
